📍 Cómo Funciona el Nivel 1 (Reciclaje)

Secuencia de reparación: A → B → A → ARRIBA

function cargarNivel1 () {
tiles.setCurrentTilemap(tilemap`ciudadReciclaje`)
colocarRecursosYPeligros()
dispositivo = sprites.create(
assets.image`recolector`,
SpriteKind.Equipo
)
tiles.placeOnTile(dispositivo,
tiles.getTileLocation(29, 18)
)
ponerCartel("ESCUELA", 29, 6)
ponerCartel("RECICLAJE", 30, 19)
ponerCartel("PARQUE", 8, 23)
}

Lo que hace:

  • Carga el tilemap (mapa) de la ciudad de reciclaje
  • Coloca piezas, monedas y peligros (según marcadores del mapa)
  • Crea el dispositivo "recolector" para reparar
  • Pone carteles con nombres en el mapa

📋 Estructura de Cada Nivel

Todos los niveles siguen este patrón:

function cargarNivel[X] () {
// 1. Cargar el tilemap (mapa del nivel)
tiles.setCurrentTilemap(tilemap`ciudadAgua`)

// 2. Colocar recursos y peligros
colocarRecursosYPeligros()

// 3. Crear el dispositivo a reparar
dispositivo = sprites.create(
assets.image`[imagen]`,
SpriteKind.Equipo
)
tiles.placeOnTile(dispositivo,
tiles.getTileLocation([col], [fila])
)

// 4. Colocar carteles
ponerCartel("[NOMBRE]", [col], [fila])
}

🗺️ PASO 1: Diseñar el Mapa (Detallado)

  1. En MakeCode Arcade, haz clic en el ícono de mapa (a la izquierda)
  2. Selecciona o crea un tilemap llamado ciudadAgua para el Nivel 2
  3. Dibuja el mapa usando las herramientas de pintura
  4. Usa colores para marcar dónde irán los recursos:
    • Gris = Piezas (marcaPieza)
    • Amarillo = Monedas (marcaMoneda)
    • Verde = Peligros (marcaPeligro)
  5. Deja espacio para el dispositivo que se colocará con código
  6. Asegúrate de que el mapa no tenga áreas donde se quede atrapado

💡 Consejo: Puedes copiar el mapa del Nivel 1 y modificarlo para empezar más rápido.

🔐 PASO 3: Nueva Secuencia de Reparación

Para el Nivel 2, propongo esta secuencia: A → ARRIBA → B → A

Edita la función comprobarBoton():

function comprobarBoton (boton: string) {
let esValido = false
if (nivelActual == 1) {
// Nivel 1: A B A ARRIBA
esValido = (pasoReparacion == 0 && boton == "A" ||
pasoReparacion == 1 && boton == "B" ||
pasoReparacion == 2 && boton == "A" ||
pasoReparacion == 3 && boton == "ARRIBA")
} else if (nivelActual == 2) {
// Nivel 2: A ARRIBA B A
esValido = (pasoReparacion == 0 && boton == "A" ||
pasoReparacion == 1 && boton == "ARRIBA" ||
pasoReparacion == 2 && boton == "B" ||
pasoReparacion == 3 && boton == "A")
}

if (esValido) {
pasoReparacion += 1
if (pasoReparacion == 4) {
completarMision()
} else {
actualizarContador()
}
} else {
pasoReparacion = 0
jugador.sayText("Secuencia incorrecta", 1200, false)
}
}

🎯 Propuesta de Secuencias Únicas

Nivel Tema Secuencia Dificultad
1 Reciclaje A → B → A → ARRIBA Fácil (lineal)
2 Agua A → ARRIBA → B → A Medio
3 Aire B → A → ARRIBA → B Medio-Alto
4 Naturaleza ARRIBA → B → A → ARRIBA Alto

🐛 Pruebas y Debugging

Cómo probar cada nivel:

  1. Prueba el movimiento - ¿El jugador se mueve libremente sin trancarse?
  2. Prueba la recolección - ¿Se recogen piezas, monedas y se toman daños?
  3. Prueba la reparación - ¿La secuencia de botones funciona correctamente?
  4. Prueba la transición - ¿Se pasa al siguiente nivel después de terminar?
  5. Prueba la progresión total - ¿Puedes jugar del Nivel 1 al 4 sin errores?

Si algo no funciona:

  • Revisa la consola de errores en MakeCode (esquina inferior)
  • Verifica que los nombres de tilemaps sean exactos
  • Asegúrate de que las coordenadas (col, fila) sean correctas
  • Prueba comentando el código sospechoso y activándolo gradualmente

❓ Dudas Frecuentes (FAQ)

P: ¿Cómo cambio la cantidad de piezas requeridas?

En `calcularCosto()`, usa `Math.max(1, 3 - descuentoPiezas - nivelHerramienta)`. Cambia el 3 a otro número.

P: ¿Cómo agrego más de una secuencia por nivel?

Crea múltiples dispositivos con variables diferentes. Cada uno llama a una función distinta.

P: ¿Qué pasa si no recuerdo una secuencia?

La tabla en la diapositiva 13 tiene las 4 secuencias sugeridas.

P: ¿Puedo cambiar la historia?

Sí, edita los textos en `presentarHistoria()` y `consultarMensaje()`.
